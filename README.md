## 💻 Projetos em Destaque

### 🍔 [Food Delivery System](https://github.com/KaiqueVieiraTavares/entrega-comida)
Plataforma distribuída baseada em **Microsserviços** (10 serviços incluindo Auth, Order, Delivery, etc).
* **Tecnologias:** Java 21, Spring Boot, Kafka, Docker, JWT, WebSockets.
* **Destaques:** Autenticação JWT, eventos assíncronos com Kafka e notificações em tempo real via WebSockets. Cobertura de testes com JUnit e Mockito.

### 🎵 [Music Platform](https://github.com/KaiqueVieiraTavares/music-system) *(Em desenvolvimento)*
Ecossistema de streaming musical contendo 7 serviços.
* **Tecnologias:** Java 21, Spring Boot, Kafka, Elasticsearch, PostgreSQL, MongoDB.
* **Destaques:** Busca avançada com Elasticsearch indexado por eventos Kafka. Rate limiting e validação centralizada via API Gateway.
